# Star Wars Mod Master Plan

## 🚀 Phase 1: The Basics (Weapons & Armor)
- [x] **Lightsabers**: Basic colors and 3D models.
- [x] **Blasters**: Shoot laser projectiles.
- [x] **Materials**: Durasteel and Kyber Crystals.
- [x] **Armor Sets**:
    - [x] Clone Trooper (Implemented items, needs textures)
    - [x] Mandalorian (Implemented items, needs textures)
    - [x] **Jetpack**: Functional flight for Mandalorian armor.
- [x] **Sounds**: Custom audio for sabers, blasters, and droids (Registered, needs files).

## 🤖 Phase 2: Life in the Galaxy (Mobs)
- [x] **R2-D2**: Passive droid.
- [x] **Battle Droid**: Hostile, shoots blasters.
- [x] **Stormtroopers**: Squad-based enemies, drop blaster rifles.
- [x] **C-3PO**: Chatty passive mob, maybe translates languages?
- [x] **Jawas**: Desert traders, spawn in groups.
- [x] **Ewoks**: Neutral forest dwellers, attack if provoked.
- [ ] **Yoda / Jedi Masters**: Rare spawns that teach Force powers.
- [ ] **Sith Lords (Bosses)**: Darth Vader or Maul with aggressive AI and Force powers.

## ⚡ Phase 3: The Force (Magic System)
- [ ] **Force System**: Mana/Energy bar for Force usage.
- [ ] **Abilities**:
    - *Force Push*: Knockback enemies.
    - *Force Pull*: Pull items or entities closer.
    - *Force Jump*: High vertical leap.
    - *Lightning*: Sith exclusive damage.
    - *Heal*: Regenerate health.
- [ ] **Holocrons**: Items found in structures to learn new powers.

## 🌍 Phase 4: World Generation (Biomes & Structures)
- [ ] **Biomes**:
    - *Tatooine Desert*: Red sand, twin suns (skybox), Banthas.
    - *Endor Forest*: Giant trees, Ewok villages.
    - *Hoth*: Ice plains, Wampas.
    - *Mustafar*: Volcanic ash and lava rivers.
- [ ] **Structures**:
    - *Jedi Temples*: Rare loot (Kyber crystals).
    - *Crashed Ships*: X-Wings or TIE Fighters with salvage.
    - [x] **Imperial Outposts**: Guarded by Stormtroopers/Battle Droids (Enemy Outpost).
    - [x] **Tatooine Market**: Desert village structure with Traders and Jawas.

## 🛠 Phase 5: Advanced Tech
- [x] **Lightsaber Assembly Table**: Custom UI to mix and match hilts and crystals (Lightsaber Forge).
- [x] **Hyperforge**: Special oven for processing Durasteel and Kyber Crystals.
- [x] **Circuit Table**: Workstation for crafting Droids and electronic components.
- [x] **Technological Blocks**: Imperial Plating, Death Star Panel, Durasteel Plating, Holographic Projector.
- [ ] **Droids**:
    - *Astromech*: Can sit in ships or store items.
    - *Probe Droid*: Floats and scans area.
- [ ] **Vehicles**:
    - *Speeder Bike*: Fast ground travel.
    - *X-Wing / TIE Fighter*: Flight mechanics (very complex).

## 📦 Phase 6: Polish
- [ ] **Particles**: Custom laser effects, sparks on saber clashes.
- [ ] **GUI**: Star Wars themed inventory screens.
